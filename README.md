# E-Commerce Sales and Customer Analysis

An online retail analytics study covering customer behavior, sales performance, and product trends with Python, SQL, and Power BI.

## Contents of source archive
- Python notebook: data cleaning, EDA, and RFM customer segmentation.
- MySQL analysis: revenue, orders, customers, product ranking, country sales, and average order value.
- Power BI: executive overview, customer segmentation, product and market insights.

## Highlights from the original project README
- United Kingdom generated the highest revenue.
- November and December were high-sales months.
- VIP and loyal customer segments generated significant revenue.
